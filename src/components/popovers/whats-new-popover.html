What's New Display Guidelines

1. Apple App Store (Public Listing): Rendered directly on the main store page below screenshots, showing the version, release date, and release notes.

2. Google Play Store (Update State Only): Hidden on pre-install listings. Only visible to existing users downloading an app update.

3. Console Character Limits: Google Play caps release notes at 500 characters per language (App Store allows up to 4,000 characters).
