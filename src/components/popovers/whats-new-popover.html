What's New Display Guidelines

1. Apple App Store (Public Listing): What's New is rendered directly on the main app listing page right below screenshots, displaying the version number, release date, and full release notes with a "more" expander.

2. Google Play Store (Update State Only): On Google Play, the public pre-install store listing does not show What's New. The release notes are only shown to users who already have the app installed and are downloading an update.

3. Google Play Console Compliance: When publishing any release in Google Play Console (Production or Testing), developers are required to submit Release Notes (What's new in this release) capped at 500 characters per language (App Store allows up to 4,000 characters).

4. Preview Studio Sync: What's New is preserved across both stores so you can draft, validate character limits, and export complete release notes via JSON or Markdown.
