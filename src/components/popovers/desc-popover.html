Full Description Display Guidelines

1. Google Play Store: Only displays the Short Description (80 chars) on the main page. The Full Description appears on a separate screen when tapping About this app →.

2. Apple App Store: Displayed directly on the main page below screenshots, previewing the first 3 lines with a "more" expander.

3. ASO & SEO Indexing: On Google Play, the Full Description is the primary asset for search algorithm indexing and organic keyword ranking.
