Full Description Display Guidelines

1. Google Play Store: The main product listing DOM only displays the Short Description (80 chars). The Full Description is not rendered on this page — in the official Play Store app, tapping About this app → navigates to a completely separate detail screen.

2. Apple App Store: Displays the full description directly on the main page under screenshots, truncated to the first 3 lines with a "more" expansion button.

3. ASO & SEO Keyword Indexing: On Google Play, although Full Description resides on a separate sub-screen, it is the single most critical asset for algorithm keyword indexing and organic search ranking.
