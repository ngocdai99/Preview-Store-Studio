Selected work

Cutting rendered views by 93% on a 100K+ download app

5 Phút Thuộc Bài. React Native, TypeScript, Redux-Saga.

Problem
On low-end Android phones such as the Redmi Note 11, scrolling dropped frames visibly.
Approach
I measured before changing anything. Layout Bounds showed a screen rendering about 5,200 views. I detached screens that were no longer visible from navigation, replaced heavy SVG icons with static assets, and checked GPU cost with Profile HWUI Rendering (on-screen bars and gfxinfo) after each change.
Result
Rendered views fell from 5,200 to 380, down 93%, and scrolling holds 60 FPS on the same device. A separate pass on memory cut RAM use by more than 50% and removed an out-of-memory crash on back navigation.

Moving a production app to React Native’s New Architecture

5 Phút Thuộc Bài. React Native 0.68 to 0.84.

Problem
The app had to move to Fabric and Bridgeless, and its 60+ dependencies each brought native build conflicts.
Approach
I worked through the dependencies one at a time to clear the native build errors, and moved the toolchain to Target SDK 35 (Android 15) and React 19 in the same upgrade.
Result
The production app runs on the New Architecture. The scripts I wrote along the way now automate APK/AAB builds and on-device installs over USB and Wi-Fi ADB.

Getting a health app through Apple’s review

Sức khoẻ Gia Đình Việt (AVN PMS), Ajinomoto Vietnam. Flutter, Riverpod. Sole mobile developer.

Problem
Apple rejected the app under Guideline 1.4.1 (Physical Harm) because it shows nutrition and health figures, and later under 2.1(a) (App Completeness). Google Play also rejected it over user data. The release was blocked.
Approach
For 1.4.1, I added reusable in-app citations from WHO, NIN and HUPH and bilingual disclaimers, so each health figure points to a source. For Google Play, I added data-retention transparency and in-app account deletion.
Result
The release was unblocked on both stores. TestFlight uploads now run through Fastlane and Apple Transporter CLI, so later releases skip the manual steps. I also moved 8+ core modules (130K+ LOC) to Clean Architecture and built an offline PDF export and a Vietnamese voice assistant.
